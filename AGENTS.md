## Code Instructions

KISS – prefer the simplest thing that works.
YAGNI – don’t build abstractions “just in case.”
Small, focused functions beat giant ones (Clean Code takeaway).
Is total code ≤ 500 lines and each function ≤ 60 lines? If not, refactor smaller.

When running tests or build dotnet code, use absolute paths instead of using 'cd' into directories.
